# 鸿鹄翼 V8 100 kg 新配重模型纵向控制复核（2026-08-03）

## 1. 结论

本轮针对新版“73 kg基础机 + 可调配重”的100 kg模型，完成了持续盘旋、多航段路线和
完整经典航线三级仿真。当前主要问题不是3～5 Hz俯仰内环抖动，而是转弯激发后持续的
约0.231 Hz纵向模态：TECS俯仰指令、真值俯仰、实际升降舵和高度误差具有相同主频。

本轮没有找到能在完整经典航线上稳健优于现有基线的标量参数组合。若只根据短航线或
持续盘旋选值，会得到局部最优并在完整任务上回归。因此最终保留当前有效参数，只在
4038注释中记录被否决的候选；4028和150 kg模型未修改。

最终100 kg参数：

```text
FW_PR_P          = 0.40
FW_PR_I          = 0.04
FW_PR_D          = 0.03
FW_PR_FF         = 0.90
TRIM_PITCH       = -0.09
FW_T_I_GAIN_PIT  = 0.05   # 保留积分器

FW_T_ALT_TC      = 3.5 s  # 继承4028

```

## 2. 基线问题定位

完整基线日志：

```text
build/px4_sitl_default/rootfs/log/2026-08-03/07_37_42.ulg
```

筛选条件为任务序号3～15、真值高度大于60 m、空速大于30 m/s；20 Hz重采样，10 s
移动均值用于分离低频变化。结果如下：

| 指标 | 全巡航 | 直线 | 转弯 |
|---|---:|---:|---:|
| 俯仰高通标准差 / deg | 1.255 | 1.296 | 1.106 |
| TECS俯仰指令高通标准差 / deg | 1.275 | 1.309 | 1.180 |
| 实际升降舵高通标准差 / deg | 0.534 | 0.519 | 0.599 |
| 高度误差RMS / m | 0.970 | 0.977 | 1.011 |
| 高度误差高通标准差 / m | 1.071 | 1.137 | 0.810 |
| 俯仰率跟踪误差RMS / (deg/s) | 1.233 | 1.005 | 2.028 |

基线主频为0.231 Hz。任务航段5的俯仰波动仅0.028°，航段6开始受转弯激发，航段9和
12即使基本直线飞行，俯仰波动仍分别达到1.788°和1.749°。因此现象属于转弯激发后
衰减不足的纵向闭环模态，不是航点高度指令连续跳变，也不是旧版3.86 Hz D项极限环。
TECS与俯仰率积分器均未长期饱和。

## 3. 候选试验与否决依据

### 3.1 TECS俯仰阻尼和高度时间常数

短路线中`FW_T_PTCH_DAMP=0.25、FW_T_ALT_TC=4.5 s`曾使俯仰波动约下降15%、高度
波动约下降14%，但完整日志`10_10_48.ulg`相对基线发生回归：

| 完整航线指标 | 变化 |
|---|---:|
| 全巡航俯仰波动 | +7.5% |
| 转弯俯仰波动 | +27.0% |
| 全巡航实际升降舵活动 | +17.0% |
| 全巡航高度误差RMS | +8.4% |

因此恢复`FW_T_PTCH_DAMP=0.15、FW_T_ALT_TC=3.5 s`。

### 3.2 TECS能量平衡率前馈

`FW_T_SEB_R_FF=0.8/0.9`能减小短路线俯仰指令波动，但0.8使高度误差RMS增加约19%，
0.9的俯仰改善仅约8%，均未满足收益条件，未写入机型文件。

### 3.3 滚转角和转弯油门补偿

持续盘旋中把`FW_T_RLL2THR`从20增到25，俯仰波动只下降0.4%、高度波动下降2.6%，
高度RMS反而增加8.9%；把`FW_R_LIM`从25°降到20°，俯仰和高度波动分别增加17.2%
和12.9%。两个候选均被否决，100 kg继续使用25°滚转限制和20的滚转油门补偿。

### 3.4 俯仰率D项

`FW_PR_D=0.05`在持续盘旋中一度使俯仰波动下降25.8%、高度波动下降47.9%，且未恢复
旧版3.86 Hz极限环；但完整日志`10_42_59.ulg`相对基线的全巡航俯仰波动增加9.9%、
高度RMS增加4.2%，转弯俯仰波动增加13.2%，因此恢复0.03。

### 3.5 TECS俯仰积分增益

积分器始终保留。`FW_T_I_GAIN_PIT=0.03`虽使盘旋波动下降，但最差高度误差从−1.81 m
恶化到−3.32 m。折中值0.04在短路线和盘旋均有改善，但完整日志`11_04_41.ulg`相对
基线发生以下回归：

| 完整航线指标 | 变化 |
|---|---:|
| 全巡航俯仰波动 | +6.0% |
| 转弯俯仰波动 | +20.9% |
| 转弯实际升降舵活动 | +11.1% |
| 转弯高度误差RMS | +12.8% |
| 转弯高度波动 | +15.9% |

因此保持继承的0.05，不禁用积分器。

## 4. 飞行安全回归

三次最终级完整任务（基线及两个被否决候选）均完成任务第18项、真实接地和鸭翼
`+6°→0°→−50°`刹车观察窗口；均未发生姿态发散或穿地。最终0.04候选的起飞真值
俯仰峰值为6.23°，空中滚转峰值26.22°，空速31.07～46.66 m/s。

完整任务自动验收的唯一失败仍是接地沉降率：基线约3.39 m/s，候选范围3.30～3.42
m/s。这与本轮巡航参数无明显相关性，属于既有LAND/拉平问题，应另行处理。

## 6. 下一步建议

1. 增加“经典航线航段3～12”的中程验收场景，并固定随机种子、至少重复三次；现有短
   路线和单向盘旋不足以代表完整任务。
2. 直接从`tecs_status`建立0.231 Hz闭环频率响应，分别估计TECS指令链和机体纵向模态
   的相位/增益；不要继续盲扫单个参数。
3. 若重复试验确认该模态稳定存在，优先设计仅对巡航俯仰指令生效的有界二阶滤波或
   阻尼环，并对起飞/降落进行旁路与平滑切换；不要修改官方TECS全局行为或气动表。
4. 只有在控制器分析排除闭环原因后，才复核`Cmq`、`Cmalphadot`及100 kg惯量；气动
   数据不应为了拟合单条闭环航迹而调整。
