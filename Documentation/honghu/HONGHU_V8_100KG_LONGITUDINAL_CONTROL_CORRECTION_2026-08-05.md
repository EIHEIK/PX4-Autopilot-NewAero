# 鸿鹄翼 V8 100 kg纵向振荡复核与更正报告

日期：2026-08-05

适用机型：`4038_gz_honghu_wing_100kg_v8_xiangyi_test`

结论：撤销2026-08-04的“0.68°可接受”判断，以最坏30 s滑窗和振幅增长率重新验收。

## 1. 为什么原结论错误

用户提供的高度和真实俯仰曲线显示，约300 s后出现持续的等周期振荡，真实俯仰振幅
逐渐增长。这与`14_24_54.ulg`完全一致，并非QGC显示尺度问题。

原分析只报告任务序号3～15的全程高通标准差。前约200 s包含大量平稳数据，因而把
后半段严重振荡稀释为0.735°左右。修正后的30 s滑窗指标为：

| 旧参数`SEB_R_FF=1.0, PTCH_DAMP=0.15` | 数值 |
|---|---:|
| 全程俯仰高通标准差 | 0.735° |
| 最坏30 s俯仰标准差 | **1.343°** |
| 最坏30 s俯仰峰峰值 | **5.33°** |
| 末段/初段俯仰标准差比 | **2.12，振荡增长** |
| 最坏30 s高度误差标准差 | **0.937 m** |
| 末段/初段高度标准差比 | **2.74，振荡增长** |

同时发现分析器把离散的`mission_result.seq_current`做了线性插值，使单航段筛选失效。
现已改为零阶保持，并新增最坏窗口、末段窗口、峰峰值和末段/初段增长率。

## 2. 真实控制架构边界

当前起飞、巡航和降落并不是三套独立PID：

- `FW_PR_P/I/D`和`FW_P_TC`三阶段共用；
- 分阶段的是俯仰角上限、正俯仰率上限和`FW_PR_FF_RWTO/FW_PR_FF_LND`；
- 起降专用FF只在对应轮控窗口和正俯仰率指令时生效；
- 正常巡航使用共同的`FW_PR_FF`；
- TECS的高度/能量控制参数在正常巡航中也是共同参数。

内环稳定并不保证整个“俯仰率—姿态—TECS高度”串级闭环稳定。旧日志在0.244 Hz处：

- 俯仰率指令到真实俯仰率增益约1.137，相干度0.998；
- TECS俯仰指令到真实俯仰相干度0.999。

因此真实飞机是在较准确地跟踪一个自身不断振荡的TECS俯仰指令，主要问题位于TECS
能量平衡环，而不是舵效不足或飞机不可控。

## 3. TECS因果分解

按当前TECS源码，俯仰指令可以由ULog中的能量平衡率严格重构：

```text
pitch_sp = [PTCH_DAMP·(SEB_rate_sp-SEB_rate)
            + SEB_R_FF·SEB_rate_sp] / (TAS·g)
           + pitch_integrator
```

重构与日志`pitch_sp_rad`的RMSE约`1e-7°`。在旧参数航段9～12中，各项10 s高通
标准差约为：

| 分量 | 标准差 |
|---|---:|
| `SEB_R_FF=1.0`前馈项 | 0.954° |
| `PTCH_DAMP=0.15`误差项 | 0.621° |
| 俯仰积分项 | 0.156° |
| 合成TECS俯仰指令 | 1.525° |

在该工作点，所谓`PTCH_DAMP`项受高度率、空速率和机体相位滞后影响，与前馈项同相
叠加。因此此前把`PTCH_DAMP`提高到0.20反而变差是符合日志证据的。这里的
`PTCH_DAMP`不是直接对真实俯仰率作负反馈的普通D项。

## 4. 不使用陷波的修正方案

保持已验证的俯仰率内环、姿态环和积分器，只把100 kg的TECS参数调整为：

```text
FW_T_SEB_R_FF   = 0.5
FW_T_PTCH_DAMP  = 0.0
FW_T_I_GAIN_PIT = 0.05
FW_T_ALT_TC     = 4.5 s
```

`0.5`是PX4参数定义允许的`FW_T_SEB_R_FF`最小值。没有加入陷波、没有关闭积分器、
没有修改气动模型，也没有修改150 kg或V3。

## 6. 分航段结果

旧方案航段9～12俯仰高通标准差为1.089/1.176/1.285/1.144°。修正方案首架对应为
0.053/0.349/0.443/0.047°。航段7～8仍包含转弯和任务切换瞬态，但进入后续直线段后
能快速衰减，不再形成持续周期振荡。

## 7. 起飞、降落和鸭翼回归

第二架次结果：

| 项目 | 数值/状态 |
|---|---:|
| 离地空速 | 40.47 m/s |
| 起飞真值俯仰峰值 | 5.97° |
| 空中俯仰峰值 | 7.19° |
| 空速范围 | 30.95～46.08 m/s |
| 接地下沉率 | 2.89 m/s，未比既有结果恶化 |
| 接地后最大滚转/俯仰 | 3.45° / 1.23° |
| 接地后最低真值高度 | -0.000059 m，未穿地 |
| 鸭翼 | 空中约+6°，接地后完成收回、延时和−50°刹车 |

自动工具仍因通用的“接地下沉率<1 m/s”检查显示`FAIL`，但该项是已有LAND/拉平遗留
问题；本次2.89 m/s没有恶化。除此以外的起飞、任务、接地、姿态、地面和鸭翼检查
均通过。

## 8. 当前验收规则

以后纵向振荡验收不得只使用全程标准差。至少同时要求：

- 最坏30 s俯仰高通标准差不超过0.65°；
- 后半程30 s俯仰标准差不高于前段，即增长率小于1；
- 最坏30 s高度误差标准差不超过0.65 m；
- 分航段结果中，直线段不得保留由前序转弯激发的持续振荡；
- 高度RMS、起飞、降落和舵面活动不得明显退化。

修正方案两次完整任务满足上述振荡条件。当前不需要陷波；若以后新工况重新出现窄带
增长模态，才重新评估结构优化。
